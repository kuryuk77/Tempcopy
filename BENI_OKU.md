# Ekran Kesiti

Ekranın bir bölümünü seçip **galeriye kaydetmeden panoya kopyalar**.

## Derleme (Android Studio)
1. Zip'i açın. Android Studio → **File → Open** → `EkranKesiti` klasörünü seçin.
2. Gradle senkronizasyonu bitsin (ilk seferde birkaç dakika sürebilir).
3. Telefonu USB ile bağlayın (USB hata ayıklama açık) → yeşil **Run ▶** düğmesine basın.
   Ya da **Build → Build App Bundle(s) / APK(s) → Build APK(s)** ile APK alın.

## Telefonda kurulum
1. Uygulamayı açın → **"Erişilebilirlik iznini aç"** → İndirilen uygulamalar → **Ekran Kesiti** → açın.
   - Gri ve açılmıyorsa: Uygulama bilgisi → sağ üst ⋮ → **Kısıtlı ayarlara izin ver**.
2. **"Hızlı ayarlara düğme ekle"** → Ekle.
3. Pil tasarrufu → **Kısıtlama yok**, Otomatik başlatma **açık**.

## Kullanım
Kontrol panelinden **Ekran Kesiti** düğmesine basın → alanı çizin → **Kopyala**.
Köşelerden boyutlandırabilir, içinden tutup taşıyabilirsiniz.
Alternatif tetik: Erişilebilirlik ayarında servisin **kısayolunu** açarsanız erişilebilirlik düğmesi / hareketiyle de çalışır.

## Notlar
- Kopyalanan görsel uygulamanın gizli önbelleğinde durur, 24 saat sonra silinir.
- Bankacılık gibi "güvenli" ekranlarda Android ekran görüntüsüne izin vermez.
- Min. Android 12. Play Store'a uygun değildir (kişisel kullanım).
